📊 풍수해보험 가입통계 엑셀 취합기

각 보험사별 가입통계 엑셀 파일(.xlsx)을 업로드하면 시군구별·시도별로 각 보험사 실적과 합계를 피벗 비교표로 취합하고 Supabase DB에 자동 저장합니다[cite: 3].

📌 엑셀 파일 업로드 안내

  1. 텍스트 변환 없이, 엑셀 원본 파일(.xlsx, .xls)을 그대로 올리시면 됩니다[cite: 3].
  2. '주택 합계', '주택 상품 1/2/3', '소상공인 합계'가 각 보험사별로 정렬되며, 시도별 소계가 자동 계산됩니다[cite: 3].
  3. 취합 완료 시 Supabase 클라우드 데이터베이스에 자동 백업되어 새로고침 후에도 유지됩니다.
